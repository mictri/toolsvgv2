## 9. Fix RightSidebar — Dimensions, Background, preserveAspectRatio
- **Dimensions**: App.tsx `handleImportSvg` không còn gọi `canvas.setWidth/setHeight` — thay bằng dispatch `resize-artboard` event để controller cập nhật artboard rect. Canvas element tự resize qua ResizeObserver, không can thiệp thủ công.
- **Background**: Thêm `setArtboardBackground(color)` trong CanvasController + `update-artboard-bg` custom event. RightSidebar dispatch event này khi:
  - Đổi màu background → artboard rect fill = màu chọn
  - Toggle Solid Background checkbox → ON = màu đã chọn, OFF = `transparent`
- **preserveAspectRatio**: Default trong store đổi từ `'xMidYMid meet'` → `'none'`. `svgSerializer.ts` nhận `preserveAspectRatio` trong options và inject vào `<svg>` tag. Cả SVG export và HTML export đều truyền giá trị này.
